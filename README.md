# 🍽️ Gestion de Restaurant

Application web de gestion de restaurant développée en **PHP / MySQL** dans le cadre d'un mini-projet académique à l'ISPM Antananarivo.

## 📋 Fonctionnalités

- Gestion des menus et des plats
- Gestion des commandes
- Gestion des stocks
- Interface d'administration

## 🛠️ Technologies utilisées

- **Frontend** : HTML5, CSS3, JavaScript
- **Backend** : PHP 8
- **Base de données** : MySQL 8
- **Environnement** : XAMPP (développement en local)
